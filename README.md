# La Milpa · El Parián
Sitio HTML estático para GitHub Pages. Abre index.html junto a styles.css, parian.css, carta.css, config.js, experience.js, menu.js, map.js y assets.

La carta conserva 21 opciones, porciones y precios del menú recibido. Tiene fotos de referencia, desplazamiento táctil horizontal, arrastre con ratón y flechas del teclado. Categorías accesibles; guía discreta y contador. Diseño de papel cálido, títulos serif y precios separados. Jericallas corregido. WhatsApp flotante con solo icono.

La portada muestra una foto real de los portales de El Parián, autor Encogua, CC BY-SA 4.0. Autores, fuentes y licencias de fotografías en creditos.html. No son fotos propias del negocio.

Completa whatsapp, instagram, facebook, mapsQuery y mapsAddress en config.js. Sin teléfono no se inventa un destinatario; el botón muestra el aviso pendiente. El mapa se activa con ubicación exacta. Música viernes/sábado es programación propuesta, pendiente de confirmar. Alcohol sin precios recibidos: Consultar.

Validado en 320, 390, 430, 768 y 1440 píxeles: fotos cargadas, gesto táctil, teclado, categorías y sin desbordamiento. Las URLs de estilos y script de la carta llevan versión para renovar la caché al actualizar.
